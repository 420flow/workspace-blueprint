# Sicherheit

Der Blueprint weist KI-Agenten an, ein kleines Python-Programm (den Extraktor) auszuführen und Dateien anzulegen. Wenn du eine Schwachstelle findest, zum Beispiel eine Anweisung, die Agenten zu etwas Unerwünschtem bringen könnte, oder eine veränderte Kopie, die unter diesem Namen kursiert, melde sie bitte vertraulich:

- über **Security → Report a vulnerability** in diesem Repo (privat, nur für den Autor sichtbar), oder
- per Nachricht an [Finn Ole Behrends auf LinkedIn](https://www.linkedin.com/in/finn-behrends).

Bitte keine Details öffentlich posten, bevor eine korrigierte Version hier liegt.

Die jeweils sichere Fassung ist immer die Datei `BLUEPRINT.md` auf dem Branch `main` dieses Repos mit der Prüfsumme aus `SHA256SUMS`.
